B-1 production deployment (existing host, behind Cloudflare)

1. Back up the production database before updating.
2. Update the checkout in /opt/kiloric-server to the B-1 commit.
3. Run: uv sync --frozen --no-dev
4. Set these values in /opt/kiloric-server/.env without replacing other secrets:
   CORS_ORIGINS=https://kiloric.co,https://www.kiloric.co
   APP_RESET_URL=https://kiloric.co/app/reset-password
   JWT_SECRET must be a randomly generated secret, never CHANGE_ME.
   Configure SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD and EMAIL_FROM.
5. Restart: sudo systemctl restart kiloric-server
6. Through Cloudflare, verify:
   curl https://api.kiloric.co/health
   curl -i https://api.kiloric.co/v1/me/prefs
   Expected: health 200; prefs 401 without a bearer token (not 404).
7. Run the release's server tests with a test database and CORS_ORIGINS=https://kiloric.co.
8. Enable GitHub Pages with Source = GitHub Actions and custom domain kiloric.co.
   Point the domain's DNS to GitHub Pages; retain api.kiloric.co's existing API origin.
   Run the Publish b-1 website workflow after the API is deployed.

The checked-in nginx.conf is a template for the API hostname. Keep the existing
Cloudflare origin access restrictions, TLS settings and firewall rules.
The Pages workflow exports the application to website/app; website/index.html is
the independent root page. GitHub Pages cannot execute the Python server.
